# JOB TRACKER V1

## Simple CLI tool to help log hours for gig jobs.

### Summary
A tracker designed for users juggling multiple 'gig' or informal jobs 
which might require the employee to keep a log of their own time worked (either hours or session depending on the agreement). This is V1 of what I hope to 
ultimately turn into a mobile app. The bare bones of the idea is a CLI
tool using Python and SQL with a sqlite3 database. Future versions of this 
program might include customized fields for specific jobs,(e.g for a tutoring job
the user might want to store teacher's or parent's numbers etc) and maybe an employers-side element where for example, a tutoring management company can have a dashboard of all their tutors completed hours with relevant data via a shared system.

## Feature Scope
- Custom job categories
- Log completed jobs
- Log partial job completion
- Interactive CLI
- Log complete and partial payments
- Retrieve relevant job data
